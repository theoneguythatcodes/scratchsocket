# scratchsocket
The official repository of ScratchSocket!

<br> (I think I had so much time with HTML)
To handle a WebSocket server PLS download Node.js and put the code that is on "resources/init_ws.js"

To enable connection on client enter to settings (UI) after copypasting the URL of the WebSocket server and put the server.

Open "server_links_history.txt" and refresh the project of the client. (this cuz the files extension doesn`t work very well on re-editing existing files)

Put the "external_cli" object in your game and configure it to make different purposes.
