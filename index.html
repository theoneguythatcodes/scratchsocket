ScratchSocket

Comunicación en tiempo real entre proyectos de Scratch y servidores mediante WebSocket.

Ver arquitectura Documentación

¿Qué es ScratchSocket?

Una infraestructura para conectar Scratch con servicios externos en tiempo real.

🔌

WebSockets

Comunicación bidireccional y persistente entre clientes y servidores.

🛡️

Nodo de seguridad

Permite añadir una capa intermedia para procesar, validar y proteger las conexiones.

⚡

Tiempo real

Diseñado para intercambiar información rápidamente entre Scratch y servicios externos.

│      Server/PC      │

           │
           ▼

           │
           ▼

           │
           ▼
┌─────────────────────┐
│      Receiver       │
│    external_cli     │
└─────────────────────┘

Diseñado para proyectos de Scratch

ScratchSocket puede utilizarse como puente entre un proyecto de Scratch y una infraestructura externa.

  • Comunicación cliente-servidor
  • Procesamiento intermedio opcional
  • Arquitectura modular
  • Comunicación mediante WebSocket
